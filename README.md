# scoop-bucket

[Scoop](https://scoop.sh) packages by nickaqmal02.

```
scoop bucket add nickaqmal02 https://github.com/nickaqmal02/scoop-bucket
scoop install kaizenotch
```

| Package | What it is |
|---|---|
| `kaizenotch` | [KaizeNotch](https://github.com/nickaqmal02/KaizeNotch): pomodoro timer and habit tracker in a pill at the top of your screen |

Update: `scoop update kaizenotch`. Remove: `scoop uninstall kaizenotch`.

KaizeNotch needs Microsoft's WebView2 runtime (already part of Windows 11; on Windows 10 install it
from https://developer.microsoft.com/microsoft-edge/webview2/ if the app does not open).
